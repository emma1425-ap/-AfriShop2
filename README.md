# AfriShop

Site vitrine d'AfriShop, une boutique de produits africains : accueil, catalogue de trois produits et contact.

## Auteur

Nkoth Cécilia Elvira Emma

## Technologies

- HTML5
- CSS3 (Flexbox)
- Git et GitHub pour le versionnage

## Lancer le site

1. Cloner le dépôt : `git clone https://github.com/emma1425-ap/-AfriShop2.git`
2. Ouvrir le dossier cloné
3. Ouvrir le fichier `index.html` dans un navigateur
